# Release notes

## 1.1 (draft)

- **More from the knob.** City size now goes twice as far: 50 sounds like 100 did in 1.0, and 100 goes further, with more air and shimmer but no warble or harshness. We picked this voicing by ear on a vocal and a full mix.
- **Your 1.0 sessions are safe.** Sessions and presets saved with 1.0 keep the 1.0 sound. If you saved BigCity as a default preset in your DAW, re-save it to get the new voicing on new instances.
